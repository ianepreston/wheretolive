|----------|-------------|
| Local CLI -> Databricks workspace | CLI commands authenticate via profile in ~/.databrickscfg |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | databricks.yml | mitigate | No secrets in databricks.yml; workspace host URL is not sensitive; authentication via CLI profile reference (`profile: free-edition`) not inline credentials |
| T-01-02 | Information Disclosure | .databricks/ state dir | mitigate | .gitignore includes `.databricks/` to prevent committing deploy state containing workspace metadata |
| T-01-03 | Elevation of Privilege | schema grants | accept | Personal project with single user; default owner-only grants are sufficient; no explicit grants block needed |
| T-01-04 | Tampering | legacy/ directory | accept | Legacy code is archived reference only; not executed; git history preserved via git mv |
</threat_model>
